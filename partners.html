Partnerships

Liên hệ đối tác

LacVietGames hợp tác với studio, nhà phát hành, trường học, đơn vị tổ chức sự kiện và đối tác thanh toán.

Phát hành game

Nếu bạn muốn đưa game lên nền tảng, hãy đăng nhập và sử dụng Publisher Center. Game sẽ được gửi đến Admin để kiểm duyệt trước khi xuất bản.

Game giáo dục / booth sự kiện

Các đơn vị cần game ngắn, trải nghiệm triển lãm hoặc nội dung giáo dục có thể gửi mô tả dự án, thời gian triển khai và nền tảng mục tiêu.

Thanh toán và thương mại

Đối tác thanh toán có thể tích hợp thông qua API order + webhook của LacVietGames. Việc cộng Lạc Coin chỉ xảy ra sau khi server xác minh giao dịch thành công.

Thông tin cần gửi

  • Tên đơn vị / studio
  • Người liên hệ
  • Email
  • Nội dung hợp tác
  • Link sản phẩm hoặc portfolio nếu có

Thông tin email/đầu mối chính thức sẽ được cập nhật khi LacVietGames đưa hệ thống liên hệ vào vận hành thương mại.
