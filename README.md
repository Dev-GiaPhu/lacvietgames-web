# LacVietGames Web

Website tài khoản chính thức của LacVietGames.

- Frontend: GitHub Pages
- Backend: `https://lacvietgames-api-production.up.railway.app`
- Chức năng: đăng ký, xác minh email, đăng nhập, quên mật khẩu, đặt lại mật khẩu và đổi mật khẩu.

## GitHub Pages

Vào **Settings → Pages → Source → GitHub Actions** để bật trang web.

URL dự kiến: `https://dev-giaphu.github.io/lacvietgames-web/`
