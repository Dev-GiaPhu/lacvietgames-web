Bước 4

Chạy Setup Wizard

Wizard tự cấu hình object SDK theo cấu trúc game.

Trong Unity

Tools → LacVietGames → Setup

Dán Integration ID được cấp trong Publisher Center, chọn đúng cấu trúc game rồi bấm Setup SDK in Current Scene.

Wizard tự làm gì?

✓Tạo GameObject LacVietGames.
✓Gắn LacVietGamesBridge.
✓Lưu Integration ID công khai.
✓Bật DontDestroyOnLoad.
✓Tự cấu hình Auto Start nếu game mở thẳng vào gameplay.

Bước 6

Báo thời điểm gameplay thật sự bắt đầu và kết thúc

Chỉ cần phần này nếu game có Boot/Main Menu. Game mở thẳng vào gameplay thì Wizard tự bật Auto Start.

Khi người chơi bấm Play

C#
LacVietGamesBridge.Instance.GameplayStarted();

Gọi đúng lúc bắt đầu chơi thật, không gọi lúc đang ở Main Menu.

Khi trận chơi kết thúc

C#
LacVietGamesBridge.Instance.GameplayEnded();

Gọi khi trận kết thúc hoặc người chơi quay lại menu.

PlayTime reward không cần code nhận thưởng. Server tự tính thời gian giữa GameplayStarted và GameplayEnded/checkpoint.
Bước 7

Reward Lạc Coin

Unity chỉ gửi Event Key. Số coin và giới hạn nằm hoàn toàn trên server.

PlayTime

Không cần code claim

Chỉ cần GameplayStarted / GameplayEnded. Admin cấu hình mốc thời gian và số LC.

Client reward nhỏ

Quest / event đơn giản

Thêm component LacVietGamesRewardTrigger, nhập Event Key rồi nối TriggerReward() vào UnityEvent.

Hoặc C#
LacVietGamesBridge.Instance
    .ClaimReward("quest_complete");
ServerVerified

Win / reward giá trị cao

Cần backend game xác minh kết quả. Không đặt Game Server Key trong Unity/WebGL.

Publisher không nhập số LC trong Unity. Ví dụ Event Key quest_complete có thể là +20 LC hay +50 LC hoàn toàn do Admin LacVietGames cấu hình.
Bước 8

Checklist trước khi upload build

Kiểm tra những mục này là đủ cho phần lớn game WebGL.

✓Package Manager hiển thị LacVietGames WebGL SDK 1.0.3.
✓Chỉ có một GameObject LacVietGames ở scene khởi động.
✓Integration ID đúng ID được Admin cấp cho game đó.
✓Nếu có Main Menu: Play gọi GameplayStarted(), kết thúc gọi GameplayEnded().
✓Không có password, bearer token, R2 key hoặc Game Server Key trong project.
✓Build WebGL và test từ trang Play của LacVietGames để kiểm tra đăng nhập thật.
Unity Editor không thể lấy tài khoản website thật. Tài khoản thật chỉ được đồng bộ khi build WebGL chạy bên trong LacVietGames. Editor chỉ dùng chế độ simulation nếu cần test UI.
Xử lý nhanh

Lỗi thường gặp

Ưu tiên kiểm tra Console và version package trước.

Không thấy Tools → LacVietGames

Remove package rồi Add lại Git URL. Đảm bảo package là 1.0.3 và Console không có compile error màu đỏ.

GAME_INTEGRATION_NOT_APPROVED

Game chưa được Admin duyệt SDK hoặc quyền đã bị khóa. Kiểm tra Publisher Center.

INTEGRATION_ID_MISMATCH

Integration ID thuộc game khác hoặc build đang dùng ID cũ. Copy lại từ đúng game trong Publisher Center.

Không thấy account khi chạy Editor

Bình thường. Account production được lấy từ website khi chạy WebGL trên LacVietGames, không lấy trực tiếp trong Editor.

Hoàn tất

Cài package → Setup một scene → build WebGL → upload.
